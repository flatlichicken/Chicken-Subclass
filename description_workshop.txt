Ever wanted to Play terraria using chickens as weapons? No? well now you can with this mod!

features:
4 full armor sets and 2 helmets for existing armor sets.
11 accessories in total. (some of them are components for another accessory)
A bunch of chicken weapons. (I lost count)
3 kinds of chicken enemies.
a new boss
a built in redemption expansion if that mod is enabled
And a few other items.

this is my first time creating a terraria mod

discord server for mod feedback: https://discord.gg/WSUNwQ2Qjc
